# スクリーンショット

Chrome Web Store に掲載するスクリーンショットを置く場所です。

## 形式

- サイズ: **1280×800**（推奨）。640×400 も可。どちらかにぴったり合わせる必要があります
- 形式: PNG（JPEG も可）。透過なし
- 枚数: 1〜5枚。最低1枚は必須
- ファイル名: 掲載順がわかるように `01-xxx.png` のように番号を付ける

## 撮影のヒント

- Retina ディスプレイでは、1280×800 のウィンドウを撮ると 2560×1600 になります。撮影後に 1280×800 へ縮小してください

  ```sh
  magick 01-options.png -resize 1280x800! -alpha off 01-options.png
  ```

- 個人のメールアドレスや社内の URL など、見せたくない情報が写らないようにしてください

## 撮るとよいもの（案）

1. `01-options.png`: 設定画面（初期URLを設定中のタブが数件並んでいる状態）
2. `02-context-menu.png`: ページの右クリックメニュー（「このページをタブの初期URLに設定」が見えている状態）
3. `03-reset.png`: 固定タブで別ページに移動したあと、ショートカットで戻る前後（2枚を左右に並べた画像など）
